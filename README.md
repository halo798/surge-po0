# Surge 模块：Po0 流量面板

在 Surge iOS 首页面板显示 [Po0](https://console.po0.io) 服务器的**上行 / 下行 / 剩余流量**、计费方式和下次重置日期；
可选：切换网络时与每 10 分钟自动把当前出口 /24 网段加入防火墙白名单，并用“Po0 防火墙”面板显示白名单与当前出口。

## 安装

Surge → 模块 → 安装新模块，填入：

```
https://raw.githubusercontent.com/halo798/surge-po0/main/po0.sgmodule
```

安装后编辑模块参数：

| 参数 | 说明 |
| --- | --- |
| `USER` / `PASS` | po0.io 登录邮箱和密码（必填） |
| `SID` | 服务编号，产品详情页上的 `#xxxx` |
| `NAME` | 面板标题 |
| `FW_TOKEN` | 控制台「防火墙 → 复制添加脚本」里 `pgnfw_` 开头的那一段；不填则不自动加白名单。不写 `@` 不锁定，写 `@0`–`@4` 锁定白名单第 1–5 个位置，见下文 |
| `AUTO_FW` | `1` 切换网络时与每 10 分钟自动加白名单，`0` 关闭 |
| `FW_NOTIFY` | `1` 成功也通知，`0` 只在失败时通知 |
| `INTERVAL` | 面板自动刷新间隔（秒） |

账号密码只保存在你手机的 Surge 模块参数里，本仓库不包含任何账号信息。

## 原理

- 登录 `console.po0.io`（WHMCS），调用控制台自带接口
  `/modules/servers/penguin/api/productInfo.php?serviceId=<SID>`，读取
  `txTransfer` / `rxTransfer` / `remainingTransfer` / `totalTransfer`（单位 KB）。
- WHMCS 会话绑定 IP，换网络后会自动重新登录；获取失败时面板显示上一次的缓存数据。
- 防火墙请求（`POST /api/firewall/<token>/add`）强制走 `DIRECT`，保证加入白名单的是手机真实出口 IP。白名单最多 5 条，不锁定位置时新网段会顶掉最旧的一条。
- 触发：切换网络（`network-changed`）、每 10 分钟定时兜底（抓“没切网但出口 IP 变了”）、点“Po0 防火墙”面板。定时任务只在结果变化时通知，不会每 10 分钟重复提醒。

## 锁定白名单位置（@0–@4）

**不写 `@` 就不锁定；只有写 `@0`、`@1`、`@2`、`@3`、`@4` 才锁定**，锁定的网段永不参与淘汰：

| 填写 | 含义 |
| --- | --- |
| `pgnfw_xxx` | 不锁定，白名单满时按写入时间淘汰最旧的 |
| `pgnfw_xxx@0` | 锁定白名单第 1 个位置 |
| `pgnfw_xxx@1` | 锁定白名单第 2 个位置 |
| `pgnfw_xxx@2` | 锁定白名单第 3 个位置 |
| `pgnfw_xxx@3` | 锁定白名单第 4 个位置 |
| `pgnfw_xxx@4` | 锁定白名单第 5 个位置 |

- 脚本请求 `.../add?slot=序号`；该位置原有的网段会被替换成当前网段。
- `@5` 及以上、`@a` 等写法会直接报错，**不会提交**，避免误加到不锁定的位置。
- token 由字母、数字、下划线组成（例如 `pgnfw_ab_cd12`），脚本会完整发送；也可以直接粘贴控制台「防火墙 → 复制添加脚本」的整段内容或整条链接，全角 `＠１` 也能识别。
- 同一网段只能占一个位置。如果当前网段已经锁在别的位置，接口会返回 403，面板和通知会提示“先在控制台防火墙里删掉旧记录”。
- 多台 po0 机器用英文逗号分隔，可混用：`pgnfw_A@0,pgnfw_B`。
- 建议只给家宽等固定出口锁定位置；手机在蜂窝 / 不同 Wi-Fi 之间切换时，锁定会让每次切网都替换掉该位置上的旧网段。

## “Po0 防火墙”面板

点一下面板（或每 10 分钟自动刷新）会立即加白，并显示：

```
当前 🛜 Wi-Fi「Home」 · 出口 203.0.113.0/24
✅ 锁定 @0 · 白名单 3/5
  203.0.113.0/24 🛜Home 📌@0 ←
  198.51.100.0/24 📶
  192.0.2.0/24 ❔
📶蜂窝 🛜Wi-Fi ❔其他设备 📌锁定 ←当前
v2026.11.16-3 · 10:23
```

- 📶 = 本机用蜂窝数据加入的网段；🛜 = 本机用 Wi-Fi 加入的网段（后面是 Wi-Fi 名称）；❔ = 其他设备或手动加入的网段。
- 📌@N = 锁定在第 N+1 个位置；← = 当前出口所在网段。
- 防火墙按 /24 网段加白，服务端只返回网段，所以“出口”显示的是 `x.x.x.0/24`。
- 最后一行是脚本版本，用来确认 Surge 跑的是最新脚本。

## 排查

- 面板最后一行不是最新版本号：到 Surge 模块列表更新本模块；仍不对就删除模块后重新安装。
- “token 无效”：到控制台「防火墙 → 复制添加脚本」重新复制 `pgnfw_` 开头那段，粘贴到 `FW_TOKEN`。
- Surge 的脚本日志里有每次请求的 HTTP 状态和服务端原始返回（token 已打码），可以截图发给维护者排查。
